# 剧情四钮跳转

线下剧情右缘加四个半透明圆钮，长剧情里不用一指一指往上划：

- `⇤⇤` 回到最上面
- `⇡` 上一次我的发言
- `⇣` 下一次我的发言
- `⇥⇥` 跳到最新

只在「线下模式」页、且已经有剧情轮次时出现；切到别的页面自动隐藏。剧情还没开始时也不显示。

## 它碰什么

**只改界面。** 不读聊天记录、不读人设、不读配置、不读密钥，不发任何网络请求，不在 `data/` 下写任何文件。全部功能就是给页面加四个按钮，点击时调用浏览器自己的滚动。

`permissions` 是空数组，和代码一致。

## 和原源码补丁的差别

原来的「线下剧情增强」是一份改 `client/src/panels/offline.jsx` 的源码补丁。这个插件是功能的等价重写，不碰源码：

- 定位「我的发言」：原补丁给每条轮次加 `data-turn-user` 标记；插件改用原版天然就有的 `flex-row-reverse` 类名（用户那侧气泡外层独有）。
- Safari「回顶被补更早打断」那条修复：插件够不着 React 组件内部的锚回逻辑，**这一条没搬过来**。在 Safari 上点回顶，若恰好触发往上补历史，可能停在半路；再点一次即可。Chrome 无此问题。
- 其余（跳两端、单箭头逐条跳我的发言、下一条按视口底找）行为一致。

好处：不用改源码、不用重新 build、Uranus 升级不会被覆盖、装卸都在控制台里点一下。

## 兼容

需要 Uranus v1.23.0 以上（插件系统从这版起有）。Mac / Windows / VPS 通用——它是浏览器里的代码，跟服务端跑在哪无关。
