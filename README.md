线下剧情的两件套，合成一个插件装：

1. **右缘四个跳转圆钮** — 长剧情里不用一指一指往上划
2. **「样式」按钮** — 在线下模式页直接调两侧气泡的配色，改完即时生效、自动存服务端

只改界面，不碰存档、不读聊天记录、不发任何非同源请求。

---

## 一、四个跳转圆钮

线下剧情页右缘居中，四个半透明圆钮：

| 按钮 | 作用 |
|---|---|
| `⇤⇤` | 回到最上面 |
| `⇡` | 上一次我的发言 |
| `⇣` | 下一次我的发言 |
| `⇥⇥` | 跳到最新 |

「上一条 / 下一条」按**你自己说的话**跳，不是按每一轮。往下跳时按视口底找下一条，往上跳时找已经滚出去的那条。

样式照原版复刻：半透明纸色、细边框、悬停变实、跟着主题的深浅色走。

---

## 二、气泡样式（「样式」按钮）

进线下模式页，**「线下模式」标题右边**有个「样式」按钮，点开：

- 上面是**实时预览**，两条样例气泡，改一下立刻跟着变
- **跟随主题 / 自定义** 二选一
  - 跟随主题＝一个样式都不盖，和没装这个插件一样
  - 自定义＝用下面调的配色
- **我这边 / 角色那边** 分侧调，各有一套：底色、底色不透明度、边框色、边框不透明度、边框宽度、文字色、圆角
- 改完**即时生效**，而且**自动保存**——没有保存按钮，关掉弹窗就是存好了
- 底部「恢复默认」＝回到跟随主题

配色存在服务端，**手机调完电脑一样**。

## 怎么用

1. 控制台 → 插件 → 装上本插件，打开开关
2. **刷新页面**（`Cmd+Shift+R` / `Ctrl+Shift+R`）
3. 进线下模式页，右缘出现四个圆钮，「线下模式」标题右边出现「样式」按钮

> 换了版本还看不到东西？多半是浏览器缓存了旧文件。**把标签页整个关掉再重新打开**，比按刷新更管用。

---

## 它碰什么

**只改页面上的界面。** 不读聊天记录、不读人设、不读密钥，不发任何非同源请求，不改 `data/` 下任何文件。

调配色时向自己的插件配置接口写一次（同源、带你的登录态），那是**配置存储**，不是去别处抓数据。

`permissions` 是空数组，和代码一致。

## 已知行为

- **四钮和「样式」按钮都只在线下剧情页出现**。判定用的是「线下模式」那张卡片本身（`section[data-anchor="线下模式"]`），不是导航栏名字 —— 导航项可能叫角色名或场景名，靠名字判会误判到别的页面。

## 和原源码补丁的差别

- 原补丁把气泡样式存在 `data/offline-bubbles.json`、走 `GET/PUT /api/offline-bubbles`（新增路由）；插件用现成的 `/api/plugins/<id>/config`，不用改服务端。
- 原补丁的「样式」按钮是 React 组件；这里是纯 DOM 注入的等价实现，观感照原版复刻（直角弹窗、无投影、遮罩只压暗不模糊、行控件布局一致）。
- 原补丁的「回顶被补更早打断」那条 Safari 修复**没搬过来**（插件够不着 React 组件内部的锚回逻辑）。Chrome 无此问题；Safari 上点回顶若恰好触发往上补历史，可能停在半路，再点一次即可。
- 好处：不用改源码、不用 build、Uranus 升级不会被覆盖、装卸在控制台点一下。

## 兼容

需要 Uranus v1.23.0 以上（插件系统从这版起有）。Mac / Windows / VPS 通用——它是浏览器里的代码，跟服务端跑在哪无关。

只作用于线下剧情，线上 iMessage 气泡不受影响。
