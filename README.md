线下剧情的两件套，合成一个插件装：

1. **右缘四个跳转圆钮** — 长剧情里不用一指一指往上划
2. **「样式」按钮** — 在线下模式页直接调两侧气泡的配色与彩色毛玻璃磨砂，改完即时生效、自动存服务端

只改界面，不碰存档、不读聊天记录、不发任何非同源请求。

---

## 一、四个跳转圆钮

线下剧情页右缘居中，四个半透明圆钮：

| 按钮 | 作用 |
|---|---|
| `⇤⇤` | 回到最上面 |
| `⇡` | 上一次我的发言 |
| `⇣` | 下一次我的发言 |
| `⇥⇥` | 跳到最新 |

「上一条 / 下一条」按**你自己说的话**跳，不是按每一轮。往下跳时按视口底找下一条，往上跳时找已经滚出去的那条。

样式照原版复刻：半透明纸色、细边框、悬停变实、跟着主题的深浅色走。

---

## 二、气泡样式（「样式」按钮）

进线下模式页，**「线下模式」标题右边**有个「样式」按钮，点开：

- 上面是**实时预览**，两条样例气泡，改一下立刻跟着变
- **跟随主题 / 自定义** 二选一
  - 跟随主题＝一个样式都不盖，和没装这个插件一样
  - 自定义＝用下面调的配色
- **我这边 / 角色那边** 分侧调，各有一套：底色、底色不透明度、**毛玻璃效果（开关+百分比强度）**、边框色、边框不透明度、边框宽度、文字色、圆角
- 改完**即时生效**，而且**自动保存**——没有保存按钮，关掉弹窗就是存好了
- 底部「恢复默认」＝回到跟随主题

配色存在服务端，**手机调完电脑一样**。

### ✨ 新增：彩色毛玻璃磨砂效果（v2.2）

- **双胶囊开关（关闭 / 开启）**：不喜欢毛玻璃的用户默认不受打扰。点击「开启」瞬间呈现黄金毛玻璃质感！
- **智能透光联动**：开启时若底色不透明度仍为默认的 100%，系统会自动贴心下调至最适透光的 `60%`，毛玻璃当场肉眼可见！
- **纯百分比调节（10% ~ 100%）**：拒绝生硬的像素（px）概念，直接按直觉调节强度，默认舒适的 `60%`。
- **不只是白透**：选什么底色就是什么颜色的彩色琉璃！
  - **视觉细节**：自动附带鲜活的色彩饱和度（`saturate 130%`）与细腻的浮空漫反射阴影，透出底层壁纸光影的同时，正文字迹依然清晰不发糊。
  - **全平台支持**：针对 iOS/iPad Safari 与桌面端分别兼顾 `-webkit-backdrop-filter` 与 `backdrop-filter`。

## ⚠️ 别和补丁版同时装（重要）

本插件的两个功能（**气泡样式** + **四钮跳转**），在玩家补丁合集 `uranus_patches_awesome` 的 **05 模块**里也有一份。**同一个功能只能留一套**，同时装会出现：

- 页面上**两排四钮**——插件往页面注入一套，补丁在 React 里渲染一套
- 两套气泡样式互相覆盖，调了配色看不出效果

**装了本插件的话，05 模块只装「版本留底 + 模型与 token」就行**（04 只依赖 02，不会把补丁版气泡样式带进来）：

```bash
cd 05-线下剧情增强/files
node installer.mjs --only 02,04 --run
```

反过来，如果你已经在用补丁版的气泡样式和四钮，就别装本插件了——功能重复，还会互相打架。

> 为什么版本留底和模型 token 没有插件版：这两个要写进剧情存档的字段（服务端 `normalizeTurn` 白名单），纯前端插件做不到，只能走补丁。

## 怎么用

1. 控制台 → 插件 → 装上本插件，打开开关
2. **刷新页面**（`Cmd+Shift+R` / `Ctrl+Shift+R`）
3. 进线下模式页，右缘出现四个圆钮，「线下模式」标题右边出现「样式」按钮

> 换了版本还看不到东西？多半是浏览器缓存了旧文件。**把标签页整个关掉再重新打开**，比按刷新更管用。

---

## 它碰什么

**只改页面上的界面。** 不读聊天记录、不读人设、不读密钥，不发任何非同源请求，不改 `data/` 下任何文件。

调配色时向自己的插件配置接口写一次（同源、带你的登录态），那是**配置存储**，不是去别处抓数据。

`permissions` 是空数组，和代码一致。

## 已知行为

- **四钮和「样式」按钮都只在线下剧情页出现**。判定用的是「线下模式」那张卡片本身（`section[data-anchor="线下模式"]`），不是导航栏名字 —— 导航项可能叫角色名或场景名，靠名字判会误判到别的页面。

## 和原源码补丁的差别

- 原补丁把气泡样式存在 `data/offline-bubbles.json`、走 `GET/PUT /api/offline-bubbles`（新增路由）；插件用现成的 `/api/plugins/<id>/config`，不用改服务端。
- 原补丁的「样式」按钮是 React 组件；这里是纯 DOM 注入的等价实现，观感照原版复刻（直角弹窗、无投影、遮罩只压暗不模糊、行控件布局一致）。
- 原补丁的「回顶被补更早打断」那条 Safari 修复**没搬过来**（插件够不着 React 组件内部的锚回逻辑）。Chrome 无此问题；Safari 上点回顶若恰好触发往上补历史，可能停在半路，再点一次即可。
- 好处：不用改源码、不用 build、Uranus 升级不会被覆盖、装卸在控制台点一下。
